# ISS-024: _extractConflictSides 纯函数无单元测试

## 严重级别

MEDIUM

## 位置

- `src/app.ts:563-599` — `_extractConflictSides()` 方法

## 描述

`_extractConflictSides` 是解析 git 冲突标记（`<<<<<<<` / `=======` / `>>>>>>>`）的纯函数，逻辑非平凡但零测试覆盖。边界情况：

- 嵌套冲突标记
- 空侧（ours 或 theirs 为空）
- 格式错误的标记（缺 `=======` 或 `>>>>>>>`）
- 多个冲突块在同一文件

## 缺失测试

```
- 标准三段冲突标记 → 正确提取 ours/theirs
- 嵌套冲突 → 行为明确（报错或取最外层）
- 缺标记 → 不 crash
- 多冲突块 → 全部提取
```

## 修复方案

作为纯函数，最容易补测试，不依赖任何外部状态。
